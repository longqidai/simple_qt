# 单摄像头算法迁移（2026-09-21）

来源：桌面 wifiTcp 的 opencv.cpp、pictureCal.cpp 和 mainwindow.cpp。

- 本工程当前设备类型为 GRR20：水平近点沿用界面参数 620 mm，垂直近点固定 520 mm。
- 面2成功后直接发 NEXT3，取消垂直近点摄像头测量和近点测距依赖。
- NEXT3 测垂直远点，面6完成后测水平远点；两次均使用同一只远焦摄像头。
- 六参数顺序保持：水平近点、水平远点、水平测距、垂直近点、垂直远点、垂直测距。
- 正式模式仅要求一只摄像头。多只可用摄像头时沿用本工程最后一个可用索引，
  日志会显示实际索引；枚举顺序不能保证识别镜头型号，现场需核对画面。
- 同步 HSV 红色小圆检测、小绿色光斑及窄环绿色比例、1060 mm 参考圆间距。
- 蓝胶带按上沿拟合，允许光点在胶带两侧；下方距离为负。
- 按源程序规则，像素距离大于10时毫米高度减10，小于-10时加10。
  源程序未赋值的 [-10,10] 像素区间改为保留未补偿值（阈值单位与补偿单位不同）。
- 保留本工程现有多帧稳定性检查及中位数融合，不迁入旧界面的计数器/滤波状态机。
- 保留当前机械臂 NEXT1～NEXT7 的点位与六面映射；不迁入 wifiTcp 的 GRR13 点位分支。

验证：项目 Debug 构建；laser_vision_single_camera.cpp 使用实际算法处理合成图，
检查胶带上方正值、下方负值及零距离，未连接机械臂或开启真实相机。
